# Utils layer

## Назначение
`utils` — это технические вспомогательные классы без состояния, которые переиспользуются в разных местах.

Обычно здесь находятся:

- форматирование сообщений
- нормализация строк
- конвертации
- маленькие чистые helper-функции

---

## Что реализовано в проекте

### `EmailUtils`

- нормализует email (`trim + lowercase`)
- используется в `UserService` и `UserValidator`

Зачем:

- единое правило обработки email
- меньше дублирования

### `ValidationErrorUtils`

- преобразует `BindingResult` в строку сообщений
- используется в `GlobalExceptionHandler`

Зачем:

- единый формат валидационных сообщений
- исключение копипасты

---

## Правила для utils

1. Обычно `final class` + приватный конструктор.
2. Методы чаще всего `static`.
3. Никакого состояния и побочных эффектов (по возможности).
4. Если логика становится бизнес-ориентированной — переноси в service/validator.

---

## Когда не нужно использовать utils

Не выноси в utils всё подряд.

Если это:

- бизнес-логика -> service
- доступ к данным -> repository
- инфраструктурный бин -> config

Utils — для небольших общих helper-функций.
