# `docs/example` — простой пример документации API-схемы

Эта папка показывает, как можно описывать API-схему простыми словами до того, как переходить к полному OpenAPI.

## Мини-схема ответа

```json
{
  "message": "Hello, Alice"
}
```

Человеческое описание:

- `message` — строка с готовым приветствием.

OpenAPI делает то же самое, только формально и машинно-читаемо:

- тип поля,
- обязательность,
- пример,
- вложенные объекты,
- enum-значения.
