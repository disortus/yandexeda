# `docs` — учебная документация внутри Java package

Эта папка не содержит production-код. Она нужна как учебный раздел рядом с кодом проекта.

Здесь объясняются темы, которые относятся не к одному конкретному слою (`controller`, `dto`, `security`), а к сквозной документации API.

## Что здесь лежит

- `SWAGGER_SCHEMAS.md` — подробное объяснение Swagger/OpenAPI schemas в этом проекте.

## Почему папка находится внутри `com/example/demo`

Ты просил сделать папку `docs/` в `demo/`. Поэтому она лежит здесь:

```text
src/main/java/com/example/demo/docs/
```

Так её легко найти рядом с учебным кодом. В реальных проектах документацию часто держат в корневой папке `docs/`, но для этого проекта важнее, чтобы объяснение было рядом с изучаемыми слоями Spring Boot.

## Что важно понимать

Markdown-файлы в `src/main/java` не становятся Spring beans и не участвуют в runtime-логике. Это просто файлы документации в репозитории.

Если позже проект будет упаковываться в jar, такие файлы могут попасть в исходники, но они не влияют на контроллеры, сервисы, JPA, security или Swagger.
