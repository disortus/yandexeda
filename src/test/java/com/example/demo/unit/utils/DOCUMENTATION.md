# `unit/utils` — unit-тесты helper-классов

Utils — это маленькие чистые функции без состояния. Их удобно тестировать unit-тестами, потому что они не требуют Spring, БД или mocks.

## Что тестирует `EmailUtilsTest`

- `normalize` обрезает пробелы по краям,
- приводит email к lowercase,
- безопасно возвращает `null`, если входное значение `null`.

## Почему это важно

Email используется как логин и JWT subject. Если где-то email будет `Alice@Example.com`, а где-то `alice@example.com`, можно получить дубли пользователей или проблемы с поиском. Поэтому нормализация должна быть централизованной и протестированной.

## Почему `EmailUtils` возвращает `null` для `null`

Это defensive-поведение: метод не падает на `NullPointerException`, если его случайно вызвали с `null`.

Но это не значит, что `null` email допустим в API. На входном DTO всё равно стоит:

```java
@NotBlank
@Email
```

То есть уровни защиты разные:

- DTO validation отклоняет плохой пользовательский ввод,
- utility-функция остаётся безопасной при прямом вызове из Java-кода.
